# Q1 合成裂缝监督—异常修复—Teacher–Student—独立真实审核技术路线

## 1. 目标与边界

目标是在不需要人工标注的条件下，先用可追溯的在线合成裂缝建立分割基线，再以异常修复残差提供补充证据，最后通过 EMA Teacher–Student 将模型适配到真实岩壁图像域。阶段四对独立留出真实图像执行全自动无标签稳定性审核。没有人工真值时，真实 F1、IoU 和混淆矩阵在数学上不可定义，程序不会编造这些指标。

为防止数据泄漏，数据固定划分为：

- 训练图像：图1-1至图1-8，用于合成监督、异常修复与真实无标签自训练。
- 独立留出图像：图1-9、图1-10，不进入 Teacher–Student 真实无标签训练，用于合成验证背景和全自动真实无标签审核。
- 旧 Mask：完全废弃，不作为训练、伪标签或真实评价依据。

## 2. 阶段一：合成裂缝监督

### 2.1 数据构造

1. 从真实钻孔展开图中裁取 128×128 背景图块，横向按 360° 周期边界取样。
2. 随机生成周期正弦裂缝、随机曲线裂缝和近竖直裂缝，并以程序生成的精确几何 Mask 作为真值。
3. 对裂缝随机施加暗化、亮化、颜色漂移和局部宽度变化，增加域随机化。
4. 叠加水平层理、竖向拼接线、阴影等困难负样本，其 Mask 仍为背景，迫使模型学会区分结构伪影。

### 2.2 模型与损失

- 模型：基础通道数为 8 的轻量 U-Net，输入 RGB，输出单通道裂缝 logit。
- 损失：Focal BCE 和 Dice Loss 之和，兼顾像素分类与细裂缝区域重叠。
- 优化：AdamW，学习率 1e-3，120 次迭代，梯度裁剪上限 5。
- 验证：在图1-9、图1-10背景上以独立随机种子生成 48 个合成验证样本。

## 3. 阶段二：异常修复与残差引导

### 3.1 修复任务

以同一真实背景上的“无裂缝图块”作为修复目标，“合成裂缝图块”作为输入。修复网络采用残差形式：

`repaired = clamp(input + 0.35 * tanh(residual), 0, 1)`

输出头零初始化，起始状态为恒等映射，避免修复网络大幅改动非裂缝区域。损失由 Mask 内 MAE、Mask 外 MAE 和梯度一致性组成，其权重为 4.0、2.5、0.35。

### 3.2 修复引导分割

将原图 RGB 与修复残差均值拼成 4 通道输入。阶段一的三通道权重原样迁移，新增的第四通道权重零初始化，然后微调 80 次。残差是辅助证据，不直接当作裂缝 Mask。

## 4. 阶段三：Teacher–Student 真实无标签自训练

1. Teacher 与 Student 从阶段二分割模型同权重启动，修复网络冻结。
2. Teacher 接收弱光度增强，Student 接收强光度、噪声和局部遮挡增强；不使用会破坏像素对齐的几何变换。
3. Teacher 概率、像素熵和修复残差共同筛选正伪标签、负伪标签和忽略区域；不确定像素不进入伪标签损失。
4. 每次迭代同时使用合成真值监督损失和真实图像伪标签一致性损失，伪标签权重线性热身至 0.35。
5. Teacher 权重由 Student 的指数移动平均更新，EMA 系数为 0.995；总迭代次数为 140。
6. 对整幅 244×1350 图像进行横向周期滑窗预测，平均融合重叠窗口，输出概率图、0/255 二值 Mask、叠加图和四联对比图。

## 5. 阶段四：独立真实无标签自动审核

### 5.1 独立性与抽样

审核集只来自未进入 Teacher–Student 真实无标签训练的图1-9、图1-10。每张图在有效纵向范围内等距抽取 8 个 244×160 窗口，共 16 个。抽样位置不依赖模型概率，可避免按模型表现挑选样本导致的偏差。

### 5.2 全自动审核内容

- 预测分布：计算每个窗口的裂缝预测像素比例、不确定像素比例、高置信像素比例和平均预测熵。
- 光度一致性：对原图施加温和亮度与对比度扰动，统计扰动前后概率平均绝对差。
- 360° 周期一致性：对原图做横向周期平移，预测后反向对齐，统计概率差和左右周期边界差。
- 阈值稳定性：计算 0.45 与 0.55 两个阈值下预测区域的交并比，检查输出是否对阈值过度敏感。
- 异常修复关联：计算裂缝概率与修复残差的相关系数，检查两条证据通道是否具有一致反应。
- 最终发布：阶段三产生的掩膜视为候选预测；阶段四完成独立留出审核、尺寸/模式/0-255像素校验后，将 10 张掩膜和对比图统一发布到“最终二值裂缝图”和“最终裂缝识别对比图”目录。
- 以上指标均为稳定性或模型响应诊断，不是精度；真实 F1 和真实混淆矩阵在结果 JSON 中明确写为 `null`。

## 6. 评价指标和现有结果

像素级统计定义为 TP、FP、FN、TN，并计算：

- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2PR / (P + R)
- IoU = TP / (TP + FP + FN)
- Accuracy = (TP + TN) / (TP + FP + FN + TN)
- Specificity = TN / (TN + FP)

当前可追溯结果如下；前三行均为合成验证，不是真实裂缝精度：

| 阶段 | Precision | Recall | F1 | IoU | Accuracy | Specificity |
|---|---:|---:|---:|---:|---:|---:|
| 阶段一合成监督 | 0.502747 | 0.879155 | 0.639687 | 0.470250 | 0.982305 | 0.984181 |
| 阶段二修复引导 | 0.535068 | 0.942025 | 0.682486 | 0.518010 | 0.980756 | 0.981626 |
| 阶段三 EMA Teacher | 0.496258 | 0.956157 | 0.653395 | 0.485216 | 0.977729 | 0.978213 |
| 阶段四真实无标签审核 | 无真值，不适用 | 无真值，不适用 | 无真值，不适用 | 无真值，不适用 | 无真值，不适用 | 无真值，不适用 |

阶段二修复网络的实际合成验证结果：Mask 内 MAE=0.104521，Mask 外 MAE=0.020726，整体 MSE=0.001934，PSNR=27.134604 dB。阶段三的合成 F1 低于阶段二，说明自训练并未在合成域上形成单调提升。阶段四可以自动判断真实留出图像上的预测稳定性，但在无人工真值的设定下不能证明真实精度提升。

## 7. 运行方式

在项目根目录的 PowerShell 中执行：

```powershell
.\.venv\Scripts\python.exe code\Q1.py 阶段一
.\.venv\Scripts\python.exe code\Q1.py 阶段二
.\.venv\Scripts\python.exe code\Q1.py 阶段三
.\.venv\Scripts\python.exe code\Q1.py 阶段四
```

四个命令均全自动执行，不需要用户制作或放置任何标签。阶段四直接生成逐窗口 CSV、诊断汇总 JSON、中文图表和原图对比图。

## 8. 限制与下一步

- 当前为 CPU 轻量基线，训练迭代数较少，目的是建立完整、可复现、可审计的闭环，不代表已达最优精度。
- 合成裂缝与真实裂缝仍存在域差异；无标签稳定性较好并不等于真实分割精度较高。
- 本路线坚持“不需要人工标注”的约束，因此只报告可追溯的合成精度和真实无标签诊断，不报告伪造的真实 F1。
